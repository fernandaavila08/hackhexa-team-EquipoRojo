Problema

pero el sistema no sabe cuáles son realmente importantes.

Datos
{
  "temperatura": [
    "alta",
    "baja"
  ],
  "movimiento": [
    "si",
    "no"
  ],
  "luz": [
    "si",
    "no"
  ],
  "ruido": [
    "alto",
    "bajo"
  ]
}

Reto
Decidan qué variables usarían para detectar actividad sospechosa en la ciudad 
y cuáles pueden ignorarse.
